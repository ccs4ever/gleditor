# Xuzz convergence samples

`slice_then_xanadoc/` is a combined Xanadu/Zigzag store generated by
`tools/create-sample-xanadocs.sh`. Its source choreography is `sources/slice_then_xanadoc.xuzz`; no
YAML slice is involved.

The operation history deliberately has slice genesis at operation 1, creates the dimension and cell,
adds Xanadoc text, and then independently edits the cell and document at operations 8 and 9. Inspect
`ops.export` with `build/xudu-dump --section=versions tests/samples/xuzz/slice_then_xanadoc`.
