# Dense Hypertime Loom: compaction and expansion concept

Status: visual design proposal, not an implementation or performance result. The dense mockups use
illustrative operation and branch counts. This extends the hanging liquid-glass loom and
container-thread interaction in the original mockups.

## What occupies overview space

Long single-child operation sequences become counted skeins. Their wrappers have soft seams and an
expand affordance, so they cannot be mistaken for a stored operation. A skein reports its scope,
unique operation count, and range. Fork junctions stay explicit, with distinct exit ports; a compact
branching sheaf retains separate branch exits and a head count. Shared ancestors count once.
Selected operations, pins, editions, and relevant source endpoints remain visible boundaries.
Compaction changes the presentation; it removes no operation or branch from reach.

There are three stable detail levels: a counted bundle, individual operation marks, and readable
operation tiles. Text changes between legible forms instead of shrinking continuously. Perspective,
local focus, and explicit expansion determine the level; hysteresis prevents flicker at boundaries.

## Opening a region

Before aggregation, an operation run can use [helical packing](helical-packing.md): an open
corkscrew retains individual op chips while shortening the run's spatial extent. Its focused turn
opens locally; later counted compaction remains a separate presentation stage.

An expand action unpleats a bounded section of its own thread. The section bows toward the reader,
its marks separate into readable tiles, and adjacent compact runs take up local slack. The selected
operation, pinned anchors, and container companion remain stable. Unrelated branch regions do not
undergo a global layout shuffle.

Geometry interpolates continuously while detail changes in stable steps. The first and last
operation identities and branch ports remain traceable throughout. Input can interrupt or reverse
the transition. Collapse preserves the selected operation, branch choice, pins, and return position.
Keyboard and accessibility expand, collapse, and pin actions reach the same state; reduced motion
shows the resulting arrangement directly.

A crowded view never silently collapses a pinned region. It can compact unpinned neighbors, reframe
the view, or offer a separate context track. The reader should be told which space limit applies.
The pin control shows its current state and offers an explicit unpin action. Background highlights
stay quieter than the open region; IDs, counts, and controls use stable, high-contrast text surfaces
throughout motion.

## Tugging a large container history

A container tug initially reveals a summarized reachable history, rather than spreading every
operation into a foreground tile. Its track retains branches and head counts. Only the active region
opens into individual tiles; the rest remains available as expandable skeins.

Correspondence is drawn at the displayed level. A compact run uses a labelled aggregate connection;
it is not a new stored relation. An individually shown operation has an individually identified
origin marker and tether. If its origin lies in a closed main-loom skein, expose that exact marker
inside the skein while keeping its neighbors compact. Source origins stay steady during the tug.

Gold remains shared primedia. Distant sharing strands can be bundled for display, but focused
endpoints separate into exact content-span connections. Neutral silver carries history, containment,
and contextual correspondence. No bundle invents a pairing between link endsets.

## Scale and validation

A large store needs an indexed hierarchy and a bounded visible set, with detailed content resolved
away from the render path. These images do not establish memory use, frame time, or operation-count
limits. Later implementation should measure cold opening, incremental updates, dense forks, many
pins, and interruption during expansion. Check reachability and operation identity separately from
the beauty of the rendering.
