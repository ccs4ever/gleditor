# Round 5 Disposition: `design/vagent-native-agent.md` (v0.5 -> v0.6)

- **Target Document:** `design/vagent-native-agent.md`
- **Base Version Reviewed:** `0.5` (2026-10-31)
- **Revised Version Produced:** `0.6` (2026-10-31)
- **Critics:** `security` (Security & Sandboxing Expert), `ipc` (IPC & Cross-Platform Shared Memory
  Expert), `user` (Native Agent Developer / User Journey)
- **Owner Decisions Applied:**
  - All `P20` proposals (`P20.1`–`P20.8`) approved by owner.
  - Option 1 selected for IPC wire framing (§9.1–9.3): retain canonical bencode for `.vnprog` and op
    logs (§7.1–7.2), and use a fixed 32-byte binary `FrameHeader` + zero-allocation `WireValueView`
    (`decodeValueView`) over a pre-allocated 64 KiB thread-local scratch copy on the shared-memory
    rings.

## 3. Disposition of Selected MINOR Findings

- **`security` Minors 1–5:** Added `openat2` to `ENOSYS` (§8.3), restricted `fcntl` commands (§8.3),
  clarified `VAGENT_SUPERVISOR_PID` handling, and noted `RLIMIT_CORE = 0` + `PR_SET_DUMPABLE(0)`
  (§8.1).
- **`ipc` Minors 8–9:** Specified 128-byte cache-line alignment (`alignas(128)`) for x86-64 and
  Apple Silicon (§9.1) and `MSG_CTRUNC` check on `fd 3` (§9.3).
- **`user` Minors 1–2:** Specified `pkg-config` (`vagent-native.pc`) installation in §5.1 / §14.1
  and `--ledger` default path in §5.1 / §14.2.
