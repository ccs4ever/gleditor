# P19 requirement traceability matrix

Authority: [P19 v1.5](../../vagent-dynamic-source-weighting-and-epistemic-arbitration.md). Code
baseline: HEAD `3ae8d384` on `design/vagent-epistemic-arbitration`, taken as the code of record (34
commits after `8ec71fc6` were made outside the gate process). This file is the live ledger for P19
completion; the [remaining-work plan](remaining-plan.md) assigns every open row to a slice. IDs are
stable: never renumber, add new rows at the end of their section, and record a retired row in "Merge
notes" rather than deleting it.

## Status summary

The matrix holds 468 requirements merged from three independent traces of the spec (sections 1 to
3.4 and 8.1; 4 to 6.3; 7 to 9, with the 8.2 gates). **Done 90, Partial 111, Missing 231, Designed
12, Deferred by spec 9, Standing 8, Informational 7.** The 354 open rows (111 Partial, 231 Missing,
12 Designed) are what the plan has to close. Nearly half of them close in I4 (actor syntax, scoring,
queries, gates, fusion): the arbitrated query does not exist, so no actor program reaches a scope, a
score or a verdict. What is built is the ingestion half: checked ingress, per-source observation
history, the policy syntax and checker, profiles, checkpoint and resume, the VM math opcodes and the
scoped-evaluation primitive. Most consequential gaps: (1) the `upgrade(pid, CompiledProgram&)` path
skips the populated-epistemic-root refusal (X-1); (2) no query, scoring, pooling or gate exists; (3)
nothing calls `bindSource`/`observe` in production (X-3); (4) there is no epistemic-state version
cell (X-12); (5) the translator seam has no implementation, caller or test (X-20). The merge
spot-check of Done claims found 2 that did not hold (2.1-13, 2.1-5) and re-classified 9 rows whose
truth depends on nothing being built (see "Spot-check log").

Statuses: **Done** implemented and tested; **Partial** some of it (the gap is stated); **Missing**;
**Designed** only in the unaccepted `i3-2-design.md` revision 2; **Deferred** the spec places it
outside initial scope; **Standing** a constraint or fallback that holds only because the feature is
unbuilt or must stay true, re-verified at F2; **Informational** spec text with no testable
behaviour. **Target** is the chain of slices that work on the row in execution order; the last one
closes it. Slice IDs are defined in the plan.

Path conventions: `rt/` is `apps/common/xanadu/vagent/runtime/`, `vm/` is
`apps/common/xanadu/vortex/`, `xa/` is `apps/common/xanadu/`; test names are gtest `Suite.Name`
under `tests/xuzz/`. Line numbers are at the baseline HEAD and drift; re-derive them with `grep -n`
before relying on one. Evidence cells are shortened to one line; the file and test names are enough
to re-derive the rest.

Draft 2 of the plan split four slices of draft 1 and added six: I4-1 became I4-1a and I4-1b, I4-7
became I4-7a and I4-7b, I3-4b became I3-4b1 and I3-4b2, and I5-1 became I5-1a and I5-1b; W1 and W2
are the production path. Rows keep their IDs; only the Target column moved. Open rows are still 354,
each closed by one slice.
