## N1: approach and lens semantics

Alternatives: erase exactly the registry entries on reclaim, or keep the program. A lens made by a
script lives in the session registry and is reachable by a later query (`let $l := lens(...)` is a
session binding and was already kept; a bare `lens(...)` or a pivot result comes back as a row and
the registry entry stays valid for that cell). Erasing would break a lens the user was handed, so
the program is kept whole whenever the registry grew. The price is that such a script's program
cells stay for the session, as before the reclaim existed; scripts that register nothing keep the
bounded arena (`ManyEffectScriptRunsLeaveTheArenaBounded`). The check is conservative: a registry
that grew for another reason while a script was parked also keeps it.
