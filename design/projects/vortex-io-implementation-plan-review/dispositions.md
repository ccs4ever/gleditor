## Remaining bounded scope

The source-language grammar extensions and runner result types are planned APIs, not current
implementations. Any frontend without its M7 gate returns the named unsupported diagnostic and has
no synchronous fallback. Numeric budget defaults are selected from measurements at M8; until then,
`IoService` requires a complete host-resolved immutable snapshot, refuses startup if configuration
cannot resolve, returns pre-admission `BudgetExceeded` when owner work exceeds budget, and refuses
unsupported capabilities before backend calls. No code or persistent store format was changed.
