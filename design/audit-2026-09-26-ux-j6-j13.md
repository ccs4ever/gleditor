## Findings and fix locations

1. **Make results first-class across the three REPLs.** VQuery can load a store at its prompt, but
   result saving is only in its batch path (`apps/vquery/main.cpp`, around lines 441–565). VPL's
   prompt has neither open nor save (`apps/vpl/main.cpp`, around lines 131 and 385–480); its batch
   export walks compiler state, so serializing the calculated `VplView` needs an explicit check
   (`apps/common/xanadu/vpl/compiler.cpp`, around line 1272). VProlog can assert and consult a
   source file but cannot save its live clauses or export query solutions (`apps/vprolog/main.cpp`,
   around lines 30 and 123–245). Add interface commands and a common, inspectable result shape that
   preserves source cell identity through the J13 handoffs. The direct J13 arithmetic and logic
   probes prove those operations, not the pipeline.
1. **Expose the three Xuzz visibility modes.** The current keymap switches between ZigZag content
   and topology projections and moves focus between the document and slice; neither is a
   Xanadocs-only / Slices-only / Both filter. Add the view selection in `apps/xudu/main.cpp`'s Xuzz
   presentation boundary and its sovereign keymap actions in `apps/common/xanadu/system_docs.cpp`.
   Recheck focus, camera and hidden-item hit testing after a mode is available.
1. **Complete many-to-many link authoring and activity choices.** J11 could not make the one-link,
   two-cell setup. Existing link member and enter bindings do not prove traversal to an out-of-view
   cell. Add or expose endset member authoring in the Xuzz link UI (`apps/xudu/beams.cpp`, link
   panel, `apps/xudu/bridge_coordinator.cpp`), then add Activity Forward selection in the action
   table and `system://keymap`. Keep one link identity and two separate right-member cursors; record
   completed visits in `system://activity`, leaving the visited store unchanged. The
   [navigation contract](ui_workflow_xuzz_navigation.md) defines the exact behavior.
1. **Expose cell-span transclusion destinations.** The tested `Ctrl+T` path handles a document
   selection into another document; it did not establish a cell source or a new cell destination.
   Add cell-content selection and destination controls near `Views::transcludeSelection()` in
   `apps/xudu/main.cpp` and `Session::transclude()` in `apps/xudu/session.cpp`. Verify all three
   occurrences address the same primedia span before judging reopen behavior.
1. **Create numeric scalar cells through Xuzz.** The UI action exercised by J7 wrote `12` as text,
   and its persisted operation has `value=0`. Expose a scalar-entry path through the ZigZag editor
   and `system://keymap`, then confirm the stored canonical numeric bits and VPL import before
   testing sums. This run demonstrates text persistence, not numeric persistence.

audit. None of the blocked follow-on save, reopen, distant-cell or three-way transclusion effects
was counted as a pass or as demonstrated data loss.
