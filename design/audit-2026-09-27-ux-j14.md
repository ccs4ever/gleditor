The initial failed run is preserved in `/tmp/xuzz-j14` and described by commit `087fc18`. It wrote
the first four kinds to `ops.nodes`, but a directory reopen showed the earlier “New Cell” state. The
cause was `DimensionRegistry::getOrCreate()` automatically repointing the slice's designated current
version at an intermediate operation. Ordinary edits then advanced the operation head without
changing that authorial designation. The fix removes the automatic repoint. It also removes the
transclude-to-cell path's automatic current-version designation. With no explicitly designated
edition, a directory reopen uses the latest operation head; `reopened.log` shows the four saved
values with `none`, `int64`, `double`, and `bool` kinds. The activity store remains responsible for
the reader's place. Choosing the set of OSMIC current-version heads remains an authorial decision at
publish time.
