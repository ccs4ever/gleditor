Native closed-target recovery validation

Baseline and candidate runs are independent fresh-profile, headless journeys. The baseline and primary candidate each use one Xuzz process through quotation authoring, link selection, close/reopen, and retry; the separate page walk closes the target and inspects all six pages. Exact app argument vectors, full a11y logs, lossless PNG frames, raw PPM source hashes, per-checkpoint source/activity ops dumps, frozen binary hashes, and run provenance are in the three subdirectories. No executable copies or XDG profiles are archived.

The earlier baseline in baseline-full3 used xuzz 9a27360825b63e344879885e1039ad0183062e595dfe3472c3e0042e1828101e. Inspector identified Link22's selected Left occurrence as store local:3b6a3ff4fb48ede9bd7448aae1c32ed7, pinned b1, scroll0 bytes55511–55531, occurrence bytes0–20. Closing b1 caused the exact source reference to be unavailable. In the same app session, Ctrl+H and visible `T · Version b1` reopened b1, restoring the same store/pinned state/source/range; Enter created a new activity record and the Inspector showed visit 3.

The candidate refusal/retry flow is the primary proof. Candidate xuzz is 6aade8d34a679960b3789f87cc808219dcb2d01aa2ab0602b68a14907a8d7522; libgleditor.so.0 is ea4d46e75ce858119626f470045c3cc555956ad2bd4ca9425f3aeffe3e831ce9; the regular xudu-dump copy is 7031847f950135234935ae67d06c3e59da6a945bd95a5202f14591064f00947c. These hashes match before and after.

At checkpoint 05-close-b1, candidate Inspector accessibility context reports the closed endpoint's `State: b1 · bytes 0–20` and explains `Left exact source reference unavailable: Occurrence does not match the chosen document or cell frame`. Enter while closed produces the explicit Unavailable message with Cancel pending entry. The same-session map exposes and accepts `T · Version b1`; after it closes at checkpoint 08, Inspector resolves the left member again to the same local store, pinned b1, source, scroll range and occurrence span. The unavailable message remains until the explicit retry at 09, which succeeds: the current reading is b1, the UI says visit 3, and no unavailable message remains. Left 1/2 place 2/2 and Right 2/3 are preserved.

Activity snapshots show one visit record before the initial Enter; two after initial Enter; the same two after Origin, close, closed-target refusal, map, and exact reopen; then three after successful retry. The exact 08-to-09 op diff is included. `candidate-activity-payloads.json` decodes recorded permascroll spans. Its key clarification: the token following `visit2` is the parent visit ID, not the new visit ID. Op13 and op19 have duplicate payload text `visit2 1 ...` because each is a child of visit1; they are distinct MAKE-cell operations and distinct visits. The successful retry sets current visit to 3 after Origin had restored current visit 1; total completed visit records increase from two to three. Source ops dump hashes match across every checkpoint in all runs.

The candidate Inspector pagewalk was captured in the workspace-backed ignored build validation path to avoid `/tmp` quota truncation. All six pages are complete 1440x1000 frames and are included as lossless PNGs with PPM hashes and decoded-RGB equality checks. Page 3 (candidate-inspector-pagewalk/frames/07-closed-page3.png) visibly contains the local store, `State: b1 · bytes 0–20`, and the wrong-frame explanatory message, while retaining Left 1/2 place 2/2 and Right 2/3. The full a11y log labels it “Investigation 3/6”; checkpoints show no activity records added during page navigation.

All runner commands are preserved as `.sh.txt` for archival (their bytes match the executed runner). Each provenance file lists the exact six SDL/GL/XDG variables and Xvfb invocation. Each snapshot collector waited for complete 4,320,017-byte PPMs while the app remained live, then dumped current source and private activity stores during the app’s five-second capture pause. The collector does not control that pause; no per-dump timestamps were retained. The original PPM frames have been converted losslessly to PNG and each PNG's decoded RGB bytes were checked against its PPM.

The optional partial Activity Back/Walks experiments and the earlier quota-truncated pagewalk are excluded. They are not used for any claim here.
