## Completion definition

The goal is complete when the ordered service and presentation packages below are implemented
through ordinary controls and the shared command boundary; relevant J17–J32 steps pass through
actual UI with persisted state and source-store evidence; J1–J16 preservation is revalidated; and
the required headless build/test, keyboard/list, narrow/enlarged-text, reduced-motion, backend,
accessibility, and measured performance gates have evidence. No mockup, UI-tree dump, synthetic
fixture, bounded native route, or test-only entry point substitutes for a user journey. The legacy
navigation path stays available until equivalent live journeys and backend frame reviews pass. This
work does not authorize merge/deploy.

The sixteenth checkpoint closes a bounded package-retention/edition-comparison route: immutable
same-curator/name editions compare by carrier identity, explicit retention precedes enablement,
switching is explicit and guarded, emphasis is independent, and the old selected Link context
survives switch/restart. Native OpenGL proves the described local workflow. It does not complete J23
or establish publication acquisition, remote trust, D2 history, full J24, all journeys, or other
open gates.

## Current environment and accessibility checks

The recorded sixteenth environment reports AccessKit absent from that build and `dbus-run-session`
absent from its runner; its `--dump-a11y` output is an internal tree, not native AT-SPI evidence.
Check the actual candidate build rather than inheriting that result: the Makefile discovers
AccessKit through `ACCESSKIT_DIR`, `pkg-config accesskit`, or standard include paths;
`GLEDITOR_ENABLE_A11Y=1` must fail loudly if it cannot find it. Record the build's detected A11Y
configuration (and use `GLEDITOR_ENABLE_A11Y=1` for an explicit requirement), then confirm the app's
own accessibility availability report and retain `--dump-a11y` output. For native AT-SPI, check
`command -v dbus-run-session`, run the repository's `tools/ux-atspi-client.py` in its isolated
session, and confirm the AT-SPI registry daemon is available; report missing AccessKit, D-Bus
session, registry, or platform bridge as environment blockers, not product passes. The client drives
actual semantic actions; screenshots or internal tree dumps do not replace it.

For every graphical run, follow the start prompt: headless SDL offscreen, dummy audio, software GL,
and fresh `XDG_DATA_HOME`, `XDG_CONFIG_HOME`, and `XDG_CACHE_HOME` directories; preserve
run-specific profiles for restart tests. Use ordinary controls/default chords and the same input
event boundary. A step reachable only by script, direct file mutation, test fixture, or hidden
command remains a finding. Run the canonical build and owning tests after implementation; keep
runner limitations separate from regressions. This inventory itself ran no app or product test.

changes cannot trade away editing, slice construction, querying, calculation, reasoning,
publication, navigation, saving or resuming. Existing checkpoints report legacy J3/J11/J15 findings
needing reconciliation against pinned baseline, native AT-SPI and enlarged-text controls/captures

before assigning each to repaired, still failing, or not rerun; this map does not promote prior
partial passes. Keep `apps/gleditor` isolated and legacy Xuzz navigation available until parity
passes.

The project is done only after all required package gates and journey evidence are closed or an
explicitly approved scope change removes them. Until then, report each row as service implemented /
native validated / environment blocked separately, with exact evidence paths and remaining work;
never label the bounded sixteenth checkpoint as completion.
