# J17–J32 representation rerun

This rerun addresses the missing states in the first static walkthrough. It reviews a scripted
browser prototype and captured state transitions before any Xuzz implementation. It is an AI concept
review, not a human participant session or production validation.

The three requested Luna runners author independent packs and rotate their review assignments:

| Runner | Authored | Independently reviews |
| ------ | -------- | --------------------- |
| Luna 1 | J17–J21  | J22–J26               |
| Luna 2 | J22–J26  | J27–J32               |
| Luna 3 | J27–J32  | J17–J21               |

The lead compiles the packs, provides the common runtime, checks transition invariants and records
native DOM pointer and keyboard delivery in headless Chromium. Each named transition gets a browser
screenshot and a fixture identity/effect record. Dense inventories have concrete arrays and native
list search. Narrow, enlarged and reduced-motion views are captured for every journey.

Reviewers must compare each numbered task and its subclauses with actual before/after states,
explicit controls and effects. A label promising a missing action is insufficient. Contradictory
counts, versions, selections or effects require correction and another relevant check. Negative
routes are independent fixtures; the facilitator route selector is not a proposed product action.

“Concept supported” here means the requested behavior is represented coherently. Network replies,
cryptographic validation, acquisition, media playback, reader persistence, authoring, atomic commit,
operation replay and retry status remain scripted. Native browser focus, list filtering, scrolling,
layout and accessibility-tree evidence apply only to this HTML prototype. Xuzz keyboard governance,
assistive technology, storage/network diffs and rendering-backend behavior still require testing
after implementation.

The original journey specification, static run and raster mockups remain the baseline. New contracts
are explicit proposed decisions in the
[prototype contracts](../../prototypes/spatial-journeys-2026-10-13/contracts.md).
