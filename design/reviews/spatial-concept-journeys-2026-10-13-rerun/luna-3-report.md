# Independent audit: J17–J21

The final J17–J21 state pack and synchronized native browser captures now present each suite task as
a named action with a visible resulting state. All 25 base steps and all 14 alternate routes
rendered with zero browser or transition failures. I inspected the final static concept images and
representative final action frames, including the corrected filter, request identity, matching-rule,
difference-focus, exact-entry, and alternate-choice states.

All 25 base steps receive **Concept supported** as AI visual support: the action, exact
identity/status, and result state are visible in the scripted concept prototype. The status does not
imply human comprehension or production behavior. Each step in the JSON lists covered action IDs,
before/after panels, effects, PNG evidence for every captured action, and the route trace.

The four semantic issues from the prior audit are resolved in the final rendered states: J19’s
excluded inspector now agrees with Review-only; Q2 counts sit beside a clearly labeled prior Q1
snapshot; J20 labels the old H1 rule as a prior snapshot beside the active Whole-token matching
panel; and J21 shows the selected text difference, before/after range, and neighborhood. The
stale-evidence finding is also closed: the synchronized run now reports zero failures.

Alternate coverage includes 14 routes: J17 invalid, unavailable, cancel, and separately requested
V13; J18 not-held video and explicit V9 acquisition; J19 late Q1 response; J20 literal, whole-token,
numeric-unit, and missing-state variants; J21 three-state ancestry, reciprocal topology, and
unavailable target. The two action branches are compiled as independent routes with their own
screenshots and traces.

The nine cross-checks repeat for each journey. Browser-simulated keyboard focus/Enter, DOM pointer
actions, list mode, 390 px narrow view, 20 px text, computed contrast (13:1 panels and 13.6:1
reading surface), and the reduced-motion toggle are represented in the prototype. The accessibility
tree snapshot is available, but assistive technology was not tested. The run does not test real
network, persistent storage, production input handling, or human behavior.

All earlier findings are marked resolved in the JSON with their corrected screenshots. The static
source concepts remain separate evidence: they show the initial design direction, while the new
prototype states make the required transitions inspectable for this concept walkthrough.
