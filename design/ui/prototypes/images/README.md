# Generated Mock-up Prompts

All 16 mock-ups were created with the built-in imagegen tool as new raster images. The shared style
reference was [`link-context-selected.png`](link-context-selected.png) after the first frame, which
used the existing [`hypertime_dag_open.png`](../../../screenshots/hypertime_dag_open.png) capture.
The prompts asked for a landscape desktop Xuzz UI, a charcoal 3D workspace, dark navy panels, white
reading planes, exact cyan and magenta span marks, restrained gold provenance or activity accents,
short readable labels, and no brand or watermark. Each image below adds the interaction-specific
request. These are proposed interface states, not application captures.
