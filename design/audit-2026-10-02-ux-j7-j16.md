# UX Audit 2026-10-02: Real Work Journeys J7–J16 Validation

This run validates journeys [J7–J16](ux_workflow_real_work.md) against the sovereign unified
architecture in `xuzz`, `vquery`, `vpl`, and `vprolog` on branch `feat/ux-validation-j7-j16`
(merging the sovereign keymap dynamic action dispatch of `feat/vortex-ui-integration` with the
singular store loader and multi-store coordinator of `refactor/multi-store-core`).

All execution was conducted 100% headless using `SDL_VIDEODRIVER=offscreen`,
`SDL_AUDIODRIVER=dummy`, `LIBGL_ALWAYS_SOFTWARE=1`, and isolated XDG directories under
`/tmp/ux-val-real-work/`.

## Verdict

All ten journeys J7 through J16 pass end to end through program interfaces (REPL prompts, key
chords, and menu actions). Every gap reported in earlier audits that prevented real work across
these journeys has been eliminated:

1. **Numeric Persistence & VPL Calculation (J7–J8)**: Slices created via the Xuzz keyboard interface
   (`Ctrl+Alt+N`, `N`, `E`) now infer scalar numerical types (`ValueKind::Int64`, `Double`) rather
   than saving `value=0` text. `vpl` opens stores interactively via `:open`, selects ranks via
   `:rank`, calculates sums (`+/ data`), displays lattice topology via `:grid`, and saves revised
   slices via `:save`. Reopening result stores recalculates totals without retyping data.
1. **VProlog Rule Persistence & Interactive Decision (J9)**: `assert(...)` facts and rules survive
   through `:save` and reopen through `:consult` without manual `.pl` file editing. Backtracking
   through multiple solutions operates as expected.
1. **Three Xuzz View Modes (J10)**: Sovereign key chords (`Ctrl+Alt+1` Xanadoc Only, `Ctrl+Alt+2`
   ZigZag Only, `Ctrl+Alt+3` Unified Both) seamlessly switch visibility and keyboard routing while
   preserving caret position and cell focus.
1. **Many-to-Many Link Navigation & Activity Branches (J11, J16)**: Distant cell endpoints and
   independent cursor movements on both sides of a link traverse cleanly. Activity Forward and
   Activity Back allow exploring multiple saved visit branches without mutating visited stores.
1. **Three-Way Transclusion (J12)**: Focused cell spans transclude cleanly into a xanadoc caret
   position (`Ctrl+Alt+T`) and into a newly connected cell (`Alt+Shift+T`). All three locations
   address the exact same permascroll primedia spans without byte duplication.
1. **Cross-Tool Pipeline (J13)**: VQuery dataset output (`:save`) feeds directly into VProlog
   (`:open`), whose exported solutions (`:export`) feed directly into VPL (`:open`), which
   aggregates counts and saves a report slice readable in Xuzz.
1. **Value Kinds, Hypertime Branch Comparison, & Link Identity (J14–J16)**: Validated against the
   OSMIC multi-version model, six value kinds on one rank, and 3D change site navigation.

### J9: VProlog Shipping Rules & Knowledge Base Persistence

1. **Assertion & Querying**:

   ```prolog
   ?- assert(editing(issue1)).
   true.
   ?- assert(rights(issue1)).
   true.
   ?- assert(approved(issue1)).
   true.
   ?- assert(editing(issue2)).
   true.
   ?- assert(rights(issue2)).
   true.
   ?- assert(can_ship(I) :- editing(I), rights(I), approved(I)).
   true.
   ?- can_ship(issue2).
   false.
   ?- can_ship(I).
   I = issue1.
   ?- assert(approved(issue2)).
   true.
   ?- can_ship(I).
   I = issue1 ;
   I = issue2.
   ?- :save /tmp/ux-val-real-work/j9/shipping.pl
   % Saved 7 clauses to /tmp/ux-val-real-work/j9/shipping.pl
   ```

   `:consult /tmp/ux-val-real-work/j9/shipping.pl` restored all 7 clauses and yielded both `issue1`
   and `issue2` on querying `can_ship(I).`.
